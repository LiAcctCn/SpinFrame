# Demo assets

The bundled default media is:

- `music.m4a`
- `lyrics.lrc`

Other optional, legally licensed demo files can also be placed here:

- `cover.jpg`
- `transition.mp4`
- `right-video.mp4`

SpinFrame never downloads music, artwork, or video from the internet. User video tracks are always muted; the composition audio comes only from the selected music file. Missing demo files are represented by neutral placeholders and never prevent the application from starting.
